Laboratorio: diseñar un programa con IA

Unidad 3 · Semana 9 · Introducción a la Inteligencia Artificial

La semana pasada se leyeron programas de pocas líneas. Hoy se diseña un programa completo para resolver un problema de su profesión, con Gemini como compañero de diseño.

El programa va a ser más largo de lo que se puede leer línea por línea, y no hace falta. Lo importante es saber qué hace cada bloque y comprobar que el resultado es correcto.

Antes de empezar

  • Trabajar en parejas: una persona maneja el computador y la otra lee, revisa y anota.
  • Abrir gemini.google.com. No hace falta iniciar sesión.
  • Abrir JupyterLite en otra pestaña. No hace falta iniciar sesión.

Cómo usar JupyterLite

  1. En la pantalla de inicio, en Notebook, elegir Python (Pyodide). Se abre un cuaderno vacío.
  2. Para subir una tabla de datos: arrastrar el archivo .csv desde la carpeta Descargas al panel de archivos de la izquierda, o pulsar el botón de subir (flecha hacia arriba) en ese panel.
  3. Un cuaderno está hecho de celdas. Se pega el código en una celda y se ejecuta con Shift + Enter. El resultado aparece debajo.
  4. Para agregar una celda nueva, pulsar + en la barra superior del cuaderno.
  5. La primera vez que se ejecuta código, JupyterLite tarda unos segundos en cargar. Es normal.
  6. Al terminar, descargar el cuaderno con File → Download. JupyterLite guarda el trabajo solo en este navegador: lo que no se descargue, se pierde para ustedes.

Las cuatro fases

Cada programa de hoy se diseña en cuatro fases. Las dos primeras ocurren antes de ver una sola línea de código.

Fase Qué hacen Qué hace Gemini
1. Entender Describen el problema, los datos y las preguntas Pregunta lo que no está claro
2. Planificar Revisan y corrigen el plan Propone los pasos en lenguaje natural, sin código
3. Construir Ejecutan cada bloque y revisan el resultado Escribe el código de un paso a la vez
4. Comprobar Prueban con resultados que ya conocen Explica qué hace cada bloque

Cómo usar esta página

  • Los recuadros de código tienen un botón para copiar en la esquina superior derecha.
  • Los recuadros Conversar con Gemini son momentos para seguir la conversación con preguntas propias o con las sugeridas.
  • Los recuadros Revisar sirven para comprobar lo que dijo o hizo Gemini antes de seguir.
