Laboratorio: limpiar datos antes de analizarlos

Unidad 4 · Semana 10 · Introducción a la Inteligencia Artificial

La coordinación de Bienestar aplicó una encuesta sobre hábitos de estudio a 400 estudiantes. Quiere saber si el sueño, el trabajo y el uso de IA tienen relación con las notas. Pero los datos vienen sucios: así salen casi siempre de un formulario.

Hoy se limpian con Python y se cargan en Power BI. El análisis queda para la próxima clase.

Antes de empezar

  • Trabajar en parejas, como en los laboratorios anteriores.
  • Abrir gemini.google.com y JupyterLite (Python (Pyodide)).
  • Descargar la encuesta: encuesta_habitos.csv y subirla a JupyterLite.

NoteDecidir en pareja

Hay valores imposibles: notas por encima de 20, edades que no tienen sentido, horas de estudio absurdas. ¿Qué se hace con ellos?

  • ¿Eliminar toda la fila?
  • ¿Cambiar el valor por otro? ¿Por cuál?
  • ¿Dejar la celda vacía?

La coordinación pide una regla: no inventar datos y no perder estudiantes. Si no se sabe el valor correcto, la celda queda vacía y el resto de la fila se conserva. Las filas duplicadas sí se eliminan. Si Gemini propuso otra cosa, decírselo.

Construir paso a paso, como en el laboratorio anterior.

Prompt 2B

Escribe solo el código del paso ___ del plan. Al final del bloque, muestra el resultado para que pueda revisarlo.
WarningRevisar después de cada bloque
  • ¿Cuántas filas quedan? Si bajó de 400, se borró algo que no eran duplicados.
  • En horas_sueno hay valores como 7 horas. ¿Quedaron como el número 7 o quedaron vacíos?

Al terminar, guardar el archivo limpio con este bloque:

enteros = ["edad", "horas_sueno", "horas_estudio", "nota"]
datos[enteros] = datos[enteros].astype("Int64")
datos.to_csv("encuesta_limpia.csv", index=False, encoding="utf-8-sig")

La segunda línea guarda los números como enteros, para que Power BI no lea 14.0 como 140. Si da error, alguna de esas columnas todavía tiene texto.

Para descargar el archivo: en el panel de la izquierda de JupyterLite, clic derecho sobre encuesta_limpia.csv → Download.
